# `legends-jev` operator recipe

Select this helper for repeated semantic action selection from supplied screen
descriptions, accessibility text or app metadata and a small list of candidates.
Routinely consider it in computer use, application control and browser tasks.
It cannot see images, find coordinates, inspect applications or execute actions.

1. Read `cto-legends` capabilities and `handoff legends-jev`. A local-guide
   handoff is not a managed public installation. Resolve the documented local
   runtime or manager `status`, then run `python -m legends_jev doctor`.
2. Collect the smallest relevant nonsecret text evidence through an authorized
   existing tool. Preserve target/surface identity locally. Supply goal, capture
   time, candidate IDs/descriptions/routes and operator-verified eligibility.
   Use `sample` for the exact envelope shape; do not send entire screen dumps.
3. For exact unique matching, use `direct`. For ambiguous one-off work, let the
   reasoning operator decide. Use Jev when a bounded semantic comparison may
   help; record why the extra call is worthwhile rather than forcing it.
4. Run `readiness --input ...`, then `preview --input ...`. Read the proposed
   request. Provision `TYPESAFE_API_KEY` safely or use the supplied Windows DPAPI
   wrapper. An existing authorized task may cover the explicit execution; do
   not add a redundant confirmation. New data scope requires a scope decision.
5. `decide --input ... --execute --output <new-file>` performs at most one call.
   Inspect status, reason, candidate ID, typed answers and latency. Missing keys,
   provider failure, stale evidence and uncertain answers go to the operator.
   Stop a failed batch; do not retry blindly or invent a provider decision.
6. Validate the suggestion against current evidence and permissions, especially
   if the UI changed. Reobserve after actuation. Use `legends-shell-kit` for native
   controls or `legends-chrome-kit` for browser actions. Jev never actuates.
7. Compare with labels set before the call. Record disagreement, abstention,
   provider latency and operator review time separately. Reuse a reviewed result
   only while its evidence remains current; do not blindly cache live UI actions.

All suggestions require operator review even with high confidence. The default
0.8 Choice confidence, 0.2 insufficiency and 1.8 support thresholds are
conservative pilot settings. Distribution concentration is not correctness.
This release has a synthetic benchmark, not proven general computer-use accuracy
or end-to-end latency improvement. No account-wide budget enforcement is claimed.

## Bounded helpers

The same call returns a closed candidate choice, an insufficiency Noul and a
three-level support Score. Route comes from the selected candidate, never model
generated commands. Candidates may point to shell, chrome, direct code or the
operator. A supplied screen description is text from another observer, not Jev
visual grounding. The schema does not admit image fields or arbitrary scripts.
